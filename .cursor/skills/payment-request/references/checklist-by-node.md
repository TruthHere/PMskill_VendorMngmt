# 各节点请款支持文件 Checklist

优先使用履约卡片节点上的 `payment_attachments`（Skill 1 已写或已推断）。若无，按下表默认。Checklist 只在同包 `请款申请.html` 中提醒供应商应附哪些文件；MVP 不单独输出 checklist 文件。

## 通用（每次都要）

- [ ] 请款单（Payment Application，公司模板填妥）
- [ ] 发票或开票信息（若本期合同要求；模板默认金额为**不含税**）
- [ ] 本期对应 PO / 合同首页复印件（首页或关键页即可）

## 按节点语义

### 预付款 / Advance / 开工动员

- [ ] 预付款保函或合同约定的替代担保（若合同要求）
- [ ] 开工/动员证明或 PO 已生效确认
- [ ] （若有）预付款支付证书编号说明

### 到货 / Delivery / 材料设备到场

- [ ] 到货签认单（甲方或总包签认）
- [ ] 送货单 / 装箱单 / 物流签收
- [ ] 设备类：厂验/FAT 报告（合同要求时）
- [ ] 照片（可选）：到货现场，建议含水印日期

### 安装完成 / Installation / 调试 Commissioning

- [ ] 安装（或调试）完成确认单
- [ ] 测试 / 调试记录或报告
- [ ] 隐蔽工程或关键工序验收记录（若适用）
- [ ] 现场照片或监理巡检记录（若项目习惯收集）

### 验收 / Acceptance / 移交 Handover / 完工

- [ ] 验收签认单（初步/最终按合同）
- [ ] 测试 / 调试 / 竣工资料（合同清单内）
- [ ] 整改闭环证明（若曾有开项）

### 进度款 / Progress / 月度产值（总包或滚动）

- [ ] 经签认的进度款申请或工程量 / 产值报表
- [ ] 月度进度报告
- [ ] 本期变更已确认部分的引用（若金额含变更）
- [ ] 预付款抵扣说明（若适用，对应模板 Advance Payment Schedule）

### 尾款 / 质保金释放 / Retention / Final

- [ ] 最终验收或质保期满证明
- [ ] 质保金释放申请
- [ ] 保函释放或替换文件（若适用）
- [ ] 结算争议无未闭环说明（或 PM 书面豁免）

## 顾问服务节点（常见）

按合同常见拆分（阶段成果 / 中期 / 尾款），默认：

- [ ] 请款单
- [ ] 阶段成果签收或会议纪要 / 交付物清单
- [ ] 发票
- [ ] PO 复印件

## 文件名线索（后续可用于轻量检查）

| Checklist 关键词 | 文件名/类型线索 |
|------------------|-----------------|
| 请款单 | `payment` `请款` `application` `.xlsx` |
| 签认 | `签认` `签收` `acknowledg` `GRN` |
| 送货/装箱 | `packing` `delivery note` `送货` `装箱` |
| 发票 | `invoice` `发票` `fapiao` |
| 测试/调试 | `test` `commission` `调试` `FAT` |
| 进度/产值 | `progress` `BOQ` `产值` `工程量` |
| 保函 | `guarantee` `bond` `保函` |

未匹配 ≠ 一定缺失（可能扫描件文件名乱）；MVP 仅作提醒，不做重核验。
