# Project 视图 Excel 版式

目标：打开 `*_project_view.xlsx` 时，**一眼接近 MS Project 的「表 + 甘特」**。

## 工作表

单表名：`Project View`。

| 行 | 内容 |
|----|------|
| 1 | 元数据（项目名、源文件、导出时间、甘特粒度） |
| 2 | 甘特区月份带（合并单元格）；左侧表头区同色占位 |
| 3 | 左列字段名 + 甘特周/日短标签（如 `5/11`） |
| 4+ | 任务数据 + 甘特色块 |

冻结：冻住第 1–3 行 + 左侧全部字段列（甘特起点列起可横滑）。

## 左侧任务表（固定列顺序）

| 列 | 字段 | 样式要点 |
|----|------|----------|
| A | ID | 居中；摘要任务加粗 |
| B | WBS | 左对齐 |
| C | 任务名称 | 左对齐；按大纲级别 Excel indent |
| D | 工期 | 如 `5d` / `0d`（里程碑） |
| E | 开始 | `YYYY-MM-DD` |
| F | 结束 | `YYYY-MM-DD` |
| G | 前置任务 | Project 式 `3` / `3FS+2d` |
| H | %完成 | `0`–`100` |

**不放入人看版**：大纲级别（用缩进表达）、采购包（仅机读 CSV）、资源名称（源常脏/空）。

列宽：任务名称最宽（约 38）；日期约 11；其余按内容。

### 行样式

| 类型 | 字体 | 行底 |
|------|------|------|
| 摘要（Summary） | 加粗 | `#EEF2F6` |
| 普通任务 | 常规 | 白 / 斑马 `#F8FAFC` |
| 里程碑 | 常规 | 白 |

## 右侧甘特区

- 从左表下一列起为时间轴
- 粒度：`--gantt-unit week`（默认）或 `day`；跨度 > ~4 个月时强制 `week`
- **双行表头**：第 2 行月份带（`2026-05`）；第 3 行 `M/D`
- 时间轴：覆盖 `min(开始)`～`max(结束)`，按周对齐到周一/周日，**不再两端各扩一整周**

### 色块规则

| 类型 | 填充 | 含义 |
|------|------|------|
| 普通任务条 | `#5B8DEF` 蓝 | 叶子任务工期 |
| 摘要任务条 | `#334155` 深灰 | 汇总/父级（Summary） |
| 里程碑 | 黑底白 `◆` `#0F172A` | 零工期节点 |
| 关键路径任务/里程碑 | `#DC2626` 红 | 源计划 Critical |

工作簿第二页 **「图例」** 用色块样例写明上述含义；第 1 行元数据末尾提示「色例见图例工作表」。

**空单元格：无边框、无底色**，避免满屏网格淹没色块。

### 不要做的事

- 不用嵌入图表对象做甘特；**单元格填充**即甘特
- 不在甘特区叠浮动标签
- 不把采购包等机读字段塞进甘特区
