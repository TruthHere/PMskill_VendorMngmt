# 结构化导出（机读）

`*_schedule.csv` 是本 Skill 产出的扁平进度表，供其他工具或脚本继续处理。

## CSV 表头（稳定顺序）

```text
任务名称,开始日期,结束日期,采购包,ID,WBS,大纲级别,工期,前置任务,完成百分比,资源名称,是否摘要,是否里程碑,是否关键
```

| 列 | 必填 | 说明 |
|----|------|------|
| 任务名称 | ✅ | 不含缩进空格的纯名称 |
| 开始日期 | ✅* | `YYYY-MM-DD` |
| 结束日期 | 推荐 | `YYYY-MM-DD` |
| 采购包 | 可选 | 源表有则保留；MPP 常为空 |
| WBS | 可选 | 来自 Project WBS 字段 |
| 其余 | 可选 | 供追溯与筛选 |

\* 仅有结束日时，开始日可与结束日相同。

## 前四列语义

稳定保证前四列为：

- `任务名称` / `开始日期` / `结束日期` / `采购包`

与常见进度 CSV 约定（`schedule-csv-schema`）对齐，便于外部程序按列名读取。

## 结构化 xlsx

`*_schedule_structured.xlsx` 单表 `Schedule`，列与 CSV 相同，**无甘特**。

## 过滤建议

默认导出**全部任务行**（含摘要）。若只要叶子任务，可过滤 `是否摘要=否`。
