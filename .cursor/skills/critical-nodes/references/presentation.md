# 对人呈现规则（时间线 / 汇报）

本 Skill 的**机器真源**仍是 `schedule.json`（ISO 日期）。本节约束 Agent **向人汇报或生成时间线 HTML** 时的行为。

- 主交付仍是结构化 JSON，不是另做一套看板产品。
- **一旦生成时间线 HTML**，必须遵守下文视觉规则（与 SARL「请款完成时点」页同族）；禁止退回系统默认糙模板。
- 实现真源：`scripts/render_timeline.py`（改视觉先改本文，再改脚本）。

## 1. 完成时点原则（强制）

本 Skill 要回答的是：**各采购包关键节点何时完成（可触发请款）**，不是画施工工期条。

| 正确 | 错误 |
|------|------|
| 每个关键节点 / 请款节点 = **一个完成时点** | 把「BMS 安装」画成横跨数周的长条 |
| 对齐、排序、时间线圆点用 `window_end` | 用 `window_start`～`window_end` 整段当请款节点 |
| 原计划任务取 **结束日** 映射到完成时点 | 把摘要条的整段工期当成「安装节点」本身 |

- `window_start` / `window_end`：机器侧可保留作业跨度（推断落窗需要）
- **请款语义、时间线、口头/卡片汇报**：一律以 **`window_end`（完成日）** 为准
- 倒推到货等：完成时点 = 该节点窗口的结束旬（或「不晚于 …」）

## 2. 对人日期粒度（默认）

对人说明时**默认不用具体到天**，改为旬：

- `上旬`：约 1–10 日  
- `中旬`：约 11–20 日  
- `下旬`：约 21 日–月末  

格式示例：`2026年11月下旬`、`2027年1月中旬`。

JSON 内仍写 `YYYY-MM-DD`，由 Agent 在汇报时换算为旬；换算规则：日≤10→上旬，≤20→中旬，其余→下旬。

## 3. 时间线 HTML · 交互与结构（强制）

**触发**：

1. `write_critical_nodes.py --write-timeline`（Agent 落盘时）
2. Skill 1 建包后 → Agent **merge 该包节点**（见 SKILL.md）或脚本 `sync_schedule_timeline`（有已有节点时**只重渲**项目那一份 HTML）  
3. 单独 `render_timeline.py --project-root …`
4. 用户明确要求可视化时

**结构必须满足**：

1. **横向可滚动**：整块月份轴在可左右滑动的窗口内  
2. **左侧采购包列 sticky**，横滑时包名不跑掉  
3. **节点 = 完成时点圆点**，禁止工期长条  
4. 轴上圆点内显示 **节点简称**（2–3 字，如到货/安装/隔墙）；悬停看完整名称与完成旬  
5. **待确认**节点须可区分：空心圆点（白底 + 包色描边）；`inferred` 已确认后与明示同为实心；`manual` 亦须可区分  
6. **可编辑**：拖动改 `window_end`；增删节点；待确认可确认/改日期/删除。  
   - **默认（给所有人）**：双击 HTML → 编辑 →「保存全部修改」下载/另存更新后的 HTML（覆盖原文件）+ `schedule.json`（放进 `.skill/`）。下次直接打开 HTML 即是改后状态。  
   - **可选**：`serve_timeline.py` 本地服务可一点保存直写项目（无需下载）。  
7. **总包行置顶**；其余采购包分行  
8. 页下方建议有**按包摘要卡**  
9. 本地用 `file:///` 双击打开即可；禁止把本地路径写成 `https://users/...`  
10. **节假日停工色带（默认）**：…（见 `cn_holidays.py`）  
11. **项目把控区块（insights）**：今天竖线、近 30 天完成清单、待确认（可操作）。输入与推断见 [`references/timeline-insights.md`](timeline-insights.md)。

圆点位置按 `window_end` 在整段时间轴上的比例落位。

### 产出路径（脚本）

| 路径 | 说明 |
|------|------|
| `项目档案/00_进度计划/关键节点时间线.html` | **给人看的唯一文件**（PM 双击打开） |
| `.skill/critical_nodes_timeline.html` | 同内容，机器副本 |

**禁止**写入 `{采购包目录}/关键节点时间线.html`（建包过滤视图已废弃）。  
`render_timeline.py --package` 若保留：只高亮该包所在行，仍写上面两份全量时间线，**不**另存、**不**滤掉总包。

## 4. 时间线 HTML · 视觉规则（强制）

参考成品气质：冷色纸感、衬线标题、分包装色实心圆点（对齐 Desktop 上 SARL「请款完成时点」页）。  
**禁止**：系统默认无衬线堆砌、暖奶油底 + 空心小圆点、无字体层次的「脚本报表脸」。

### 4.1 字体

| 用途 | 字体 |
|------|------|
| 正文 / UI | `Instrument Sans`（Google Fonts），回退 `system-ui, sans-serif` |
| 页标题 h1 | `Newsreader`（Google Fonts），回退 `Georgia, serif` |

须在 HTML `<head>` 引入上述 Google Fonts（`preconnect` + stylesheet）。

页背景：**纯色** `--paper`，不用径向渐变装饰。  
白板：细边框即可，**不用大阴影**。  
工具栏：ghost 按钮，不单独包一层卡片。  
Tip：**浅色浮层**，不用深色块。  
下方摘要：**扁平列表**，不用卡片网格。  
节假日色带：低透明度，无描边；月头竖排小字即可。

### 4.2 色板（CSS 变量）

| Token | 值 | 用途 |
|-------|-----|------|
| `--ink` | `#1a2332` | 主文字 |
| `--muted` | `#6b7785` | 次要说明 |
| `--line` | `#e2e8ef` | 分隔线 |
| `--paper` | `#f6f8fa` | 页背景（纯色） |
| `--card` | `#ffffff` | 白板 |
| `--sticky-bg` | `#fafbfc` | sticky 包名列 |
| `--rail` | `#eef2f6` | 月格线 / 行分隔 |
| `--inferred` | `#9a8570` | 倒推描边 |
| `--holiday-spring` | `rgba(160,90,70,0.07)` | 春节色带 |
| `--holiday-labor` | `rgba(30,77,140,0.06)` | 五一/国庆色带 |

**禁止**：页头大阴影、橙色 sync 条、深色 tip、底部卡片墙、背景径向渐变。

### 4.3 分包装色（圆点填充）

每行采购包固定一色；圆点**实心填色 + 白字序号 + 白描边**，带轻阴影。推荐：

| 包 / 类型 | 色 |
|-----------|-----|
| 总包 / GC（旧 `_project` 可读） | `#1e4d8c` |
| BMS | `#0d7377` |
| 家具 | `#c45d26` |
| 配电箱 / 强电类 | `#2f6b3a` |
| 其余包 | 轮换 `#6b3fa0`、`#b45309` 等，保持饱和、可区分 |

图例（legend）用同色小圆点标包名；倒推另用虚线空心 swatch。

### 4.4 布局尺寸

| 项 | 建议 |
|----|------|
| 内容最大宽 | ~1100px，居中 |
| 包名列宽 | ~148px |
| 单月列宽 | 108px（等宽月格，便于对齐） |
| 行高 | 72px |
| 圆点 | 约 28×28px |
| 白板 | 圆角 ~14px；轻边框 + 柔和投影 |

月份头：显示「年」小字 +「M月」；底部可有上/中/下旬三分虚线刻度。  
轨道：垂直居中一条细轨线；圆点落在轨线上。

### 4.5 交互提示（tip）

- **悬停或点击**圆点弹出 tip（浅色浮层，两行：名称 · 包/旬/来源）  
- 倒推圆点：细描边 inferred 色，**不用**斜纹叠加  

### 4.6 页头与页脚文案

- 页面**只展示、不教学**：不写操作说明、apply 步骤、色带解释长文  
- eyebrow：项目名；h1：「项目采购包关键节点汇总」；图例短标签即可  
- 有未保存改动时工具栏显示「未保存」；经 `serve_timeline` 打开时「保存」直写项目  
- 页脚：分析时间 + 源路径  

### 4.7 改脚本时的检查清单

改 `render_timeline.py` 或手写时间线 HTML 时自检：

- [ ] 用了 Instrument Sans + Newsreader，不是系统默认黑体一锅炖  
- [ ] 冷色纸感底，不是暖奶油报表底  
- [ ] 分包装色**实心**圆点，不是统一空心描边小点  
- [ ] sticky 包名列 + 横滑月轴  
- [ ] tip 短、无操作说明书  
- [ ] 页面无大段操作指引文案  
- [ ] 待确认为空心圆点，已确认/明示为实心  
- [ ] 春节/五一/十一停工色带可见（与轴相交时）  
- [ ] 总包行在上；下方有按包摘要（推荐）  

## 5. Markdown / 对话摘要

按包列出请款序：

```markdown
## BMS（供装）
1. 到货 · 2026年10月下旬（倒推）
2. 安装完成 · 2026年11月下旬
3. 验收 · 2027年2月下旬
```

不要写成长区间当作单一请款节点（错误例：`安装 · 2026年10月上旬～11月下旬` 作为「一个请款节点」的唯一描述——若需交代工期可另注「作业跨度」，请款完成时点仍只标结束旬）。
