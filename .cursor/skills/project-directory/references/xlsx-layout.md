# 项目通讯录 Excel

主产物：`{项目名}_项目通讯录.xlsx`（项目根）

样式跟 Tracker 同一套灰蓝。手机号当**文本**写。

## 表「项目通讯录」

一人一行：序号、采购包、供应商、姓名、Title、手机、邮箱、更新时间。

没有回复的包不出现在这张表（去看「收集进度」）。

## 表「收集进度」

一包一行：

| 列 | 说明 |
|----|------|
| 序号 / 采购包 / 供应商 | |
| 收集状态 | 待发群消息 / 已发群待回 / 已收录 |
| 群消息日期 | 生成或确认已发到群 |
| 回执日期 | |
| 已收录人数 | |
| 备注 | |

冻结标题与表头。筛选开在表头行。
