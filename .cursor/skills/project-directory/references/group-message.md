# 群消息与填写页

通讯录**只走企微群**，不写邮件。

## 群消息

`compose_group_post.py` 写出 `项目档案/05_项目通讯录/群消息.txt`。

要点：

- 标题带 `【项目通讯录 / Project Directory】`
- 列出 Tracker 里的采购包
- 回复锚点固定为 `[PDIR]`，标签不要改
- 写明「直接回群，不必发邮件」

Agent 要把这段正文直接给用户复制，不要让用户自己翻文件（文件仍保存作底稿）。

## 填写页

同目录 `填写页.html`：手机打开、选采购包、填人、点「复制回群」。

这就是「给群机器人 / 群文件的链接」——企微里把这个 HTML 丢进群文件，供应商点开即填。不需要邮箱，也不需要外网表单。

填完复制出的内容与群消息模板同一套标签，ingest 脚本两边都能吃。
