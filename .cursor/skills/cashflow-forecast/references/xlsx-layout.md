# 现金流 Excel 表结构

主产物：`{项目名}_现金流预测.xlsx`（由 `scripts/write_forecast_xlsx.py` 生成）

## 表「现金流」

```
第1行  标题 | **检查台账更新**（点进去「台账来源」）
第2行  基础信息（合并） | 2026年1月（合并两列） | 2026年2月 | … | 结束月+1
第3行  序号 采购包 供应商 合同金额 已确认变更 PO号 请款条件 待确认 | 应请 实请 | 应请 实请 | …
第4行起 每个采购包一行
最后一行 总计（SUM 公式，改格子会跟着变）
```

- **应请**：按计划出账月（完成锚点 + 30 天）
- **实请**：已请完的节点（Tracker「下一付款节点」之前），按进度窗口月
- 空月留白，不写 0
- 冻结左侧基础信息，横向拉月份

## 表「台账来源」

列出这张表用到的台账（采购包 Tracker、变更台账、进度、各包卡片数据），可点文件名打开。

蓝色按钮 **一键检查是否有更新**：核对生成之后有没有人改过这些文件；有更新会重算 Excel。请先关掉本表再点。若 Excel 拦链接，在项目文件夹双击 `检查现金流台账.command`。

## 表「节点明细」

每个付款节点一行，用来核对应请/实请有没有对上。主表仍是「现金流」。
