# 邮件粘贴格式示例（MVP）

MVP 无邮箱集成。PM 在 Cursor 粘贴时**保留主题行**，正文按下列模板组织，便于 Agent 提取。

## 阶段 0：项目初始化

**主题**：`[项目初始化] Sample Project - SAMPLE`

**收件人（测试）**：`TestProject_AI@163.com`（或你的项目专用邮箱）

**正文**：

```
项目名称：Sample Project
项目编号：SAMPLE
项目类型：实验室
项目地址：上海市浦东新区 xxx 路 100 号
甲方名称：xxx 有限公司
项目经理：张三
币种/含税：CNY 含税
本地根文件夹路径：/Users/xxx/Projects/Sample-Project
专用邮箱：TestProject_AI@163.com
```

**附件**：完整进度计划（xlsx/pdf/mpp）

---

## 步骤 1：RFP 转发

**主题**：`SAMPLE · BMS · BOSCH — RFP`

**正文**（含供应商对接人）：

```
项目：SAMPLE
采购包：BMS（楼宇自控系统）
供应商：BOSCH Building Technologies
对接人邮箱：procurement@bosch-build.example.com
类型：纯供应

[原 RFP 邮件正文或摘要]
```

**附件**：技术要求 PDF、图纸等

---

## 步骤 2：顾问确认技术文件

**主题**：`SAMPLE · BMS · BOSCH — 顾问确认技术文件`

**正文**：注明「顾问已确认，附最终版技术文件」

**附件**：顾问签字/确认的技术文件

> **顾问服务类采购包跳过此步。**

---

## 步骤 3：Raise PO

**主题**：`SAMPLE · BMS · BOSCH — Raise PO`

**正文**：

```
项目：SAMPLE
采购包：BMS
供应商：BOSCH Building Technologies
最终金额：¥1,280,000（CNY 含税）
交期：2026-09-30 前全部到货
```

**附件**：最终版报价单

> 谈判过程邮件**不转发**；仅转发定标后的最终 PO 邮件。

---

## 步骤 4a：合同转发（有书面合同）

**主题**：`SAMPLE · BMS · BOSCH — 合同`

**附件**：合同 PDF/DOCX

Agent 从合同提取付款节点，来源标 `合同提取`。

---

## 步骤 4b：付款指示（无书面合同 / 口头约定）

**主题**：`SAMPLE · BMS · 付款条件指示`

**正文**：

```
采购包：BMS
供应商：BOSCH

付款约定（口头约定，邮件留痕）：
1. 预付款 30%，PO 签发后 7 日内
2. 到货验收 60%，全部到货并验收合格后
3. 尾款 10%，质保期满无质量问题后

请录入履约卡片，来源标注「邮件指示」。
```

---

## 步骤 5：极简归档（PO 后）

**主题**：`SAMPLE · BMS · 请款单归档`

**正文**：说明文件类型与目标文件夹（03_请款记录 等）

**附件**：请款单、变更单等

MVP 仅归档，不做请款/变更分析。

---

## 识别提示（关键词优先，主题格式可选）

**不要依赖固定标题格式。** Skill 用主题/正文关键词判断步骤：

| 关键词（示例） | 步骤 |
|----------------|------|
| `RFQ` / `RFP` / `询价` / `request for quot` | 步骤 1 |
| `顾问确认` / `技术确认` / `tech confirm` | 步骤 2 |
| `Raise PO` / `Purchase Order` / `已发PO` | 步骤 3 |
| `合同` / `contract`（非询价语境） | 步骤 4a |
| `付款条件` / `付款指示` / `请款条件` / `payment terms`（**单独**邮件时） | 步骤 4b |
| `[项目初始化]` | 阶段 0 |

**付款节点可夹带**：不要求单独转发。任意步骤邮件正文若出现请款/付款里程碑（中或英，如 `60% upon material delivery`），处理该邮件时**立即写入**卡片「付款节点」（展示 **中 / EN**），并同步 Tracker「下一付款节点」。

**金额**：Raise PO 时 **必须从报价附件（xls 等）同步抓取** `Amount before VAT` / `Include.VAT` 写入 Tracker 两列（附件优先）；邮件正文作补充。  
**对接人**：Cc 中供应商域名邮箱也会写入 Tracker。  
**归档**：落入采购包的邮件整封 `.eml` → `07_往来文件/`；报价目录不收签名图。

可选（更准）：`{项目} · {采购包} · {供应商} — {事项}`  
英文自然主题也可，例如：`FW: SARL Ph1 - Procurement - RFQ for rubber floor & carpet`  
→ 识别为步骤 1，采购包名从 `RFQ for …` 抽取；供应商未知时记为「待确认」。
