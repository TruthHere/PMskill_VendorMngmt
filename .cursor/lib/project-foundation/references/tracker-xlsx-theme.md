# Tracker xlsx 美化规范

PM 日常打开 `{项目名}_Status Tracker.xlsx`。样式由 `scripts/common.py` → `save_tracker_xlsx()` 自动应用；修改配色或布局时**先改本文档，再改代码**。

## 手动改 xlsx 会不会影响后续写入？

| 你改的文件 | 下次 Skill 保存时 |
|-----------|------------------|
| **`.xlsx` 排版**（列宽、行高、颜色、对齐） | **尽量保留** — 增量同步只改数据格 |
| **`.xlsx` 第 1 行「最后更新」** | **会更新日期文字**（不改你的合并/列宽） |
| **`.xlsx` 里程碑格填了日期** | 会同步 CSV 数据，并补上「已完成」浅色标记 |
| **`.csv` 里的数据** | **会保留**（脚本先读 CSV 再写回） |

**xlsx 写入策略（`tracker_xlsx.py`）：**

1. **文件不存在**，或**第 3 行列名与当前 schema 不一致** → **全量创建**（含主题样式）
2. **否则** → **增量同步**：按「采购包名称」匹配行，只更新单元格**值**；已有行的列宽、行高、字体、边框等**不碰**
3. **新增采购包** → 在表末追加一行并套用默认样式
4. **删除采购包** → 删除对应行

**仍会被覆盖的情况：**

- 表头结构升级（增删列）→ 触发一次全量重建
- 你手动改了某格**数据**（金额、里程碑日期）→ 下次以 CSV 为准写回
- 想强制恢复默认样式 → 删除 xlsx 后让 Skill 再保存一次

**改样式规范** → 改 `tracker-xlsx-theme.md` + `tracker_xlsx.py`，不要只靠手调 xlsx。

## 设计原则（工具表 · 分区清楚）

- **Slate 蓝灰为主**，请款区单独用暖黄点缀，打开一眼能扫到钱和进度。
- **对比度**：表头深底白字；正文 `#0F172A` on 白 / 浅灰斑马纹。
- **请款区**：暖黄底 `#FFFBEB`；偶数行更深 `#FEF3C7`；下一笔待请 `#FFF7ED` 加粗。
- **里程碑完成**：浅蓝底 `#DBEAFE` + 深蓝字 `#1D4ED8`。
- **边框**：浅灰 `#E2E8F0`，仅表格区域。
- **不写路径列**：卡片/文件夹路径不出现在给人看的表里。

## 对齐规则（全文统一，保存前 `_assert_tracker_xlsx_layout` 校验）

| 列类型 | 水平 | 垂直 | 换行 |
|--------|------|------|------|
| **序号、采购包类型、里程碑** | 居中 | 居中 | 否（表头可换行） |
| **金额不含税 / 含税 / 已请金额 / 待请款金额** | 右对齐 | 居中 | 否 |
| **采购包名称、供应商名称/简称、邮箱、备注、交期、下一付款节点、请款进度** | **左对齐** | 顶对齐（有换行）/ 居中（单行） | 是 |

名称类列**统一左对齐**，不与序号/里程碑混用居中。

##  typography

- 字体：`Microsoft YaHei`
- 正文 10pt；表头 10pt 加粗；元数据 10pt muted

## 必须换行的列

`采购包名称`、`供应商名称`、`供应商简称`、`对接人邮箱`、`金额备注`、`交期摘要`、`下一付款节点`、`请款进度`

## 行高（openpyxl 无 AutoFit，需估算）

1. 扫描上述换行列，按列宽估算行数。
2. `行高 pt = max(22, min(120, 行数 × 15 + 8))`。
3. 表头 32pt；分组行 24pt；元数据行 22pt。

## 布局

- 第 1 行：`{项目名} · 最后更新：YYYY-MM-DD`（合并整行）
- 第 2 行：请款四列合并 → **请款**（暖黄）；里程碑五列合并 → **状态**
- 第 3 行：列名（请款 / 状态列用更深表头）
- 冻结：第 4 行起
- 自动筛选：含数据时启用
- **无**「卡片路径」「文件夹路径」列

## 自检清单（改完 theme 或代码后）

- [ ] 第 1 行「项目名 · 最后更新：日期」完整可见？
- [ ] 请款区是否暖黄、下一笔待请是否加粗浅橙？
- [ ] 采购包名称 / 供应商名称等文本列是否**全部左对齐**？
- [ ] 序号 / 类型 / 里程碑 / 金额 是否分别为居中 / 居中 / 居中 / 右对齐？
- [ ] 长文本是否换行且行高足够？
- [ ] 表上有没有路径列？
- [ ] CSV 双行表头 + 脚本读入正常？

## 与 anthropics/xlsx skill 的关系

通用 xlsx skill 适合临时表格与公式；本 Tracker 以**本文档 + 代码**为准，每次保存整表重生成 xlsx。
