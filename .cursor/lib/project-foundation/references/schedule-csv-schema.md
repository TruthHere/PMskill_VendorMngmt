# 项目进度计划 CSV 规范

MVP 支持用 **CSV 项目进度文件** 替代手填 `.skill/schedule.json`。  
**fulfillment-card** `render_card.py` 渲染付款节点时会自动读取 CSV（或已导入的缓存 JSON）。

## 放置位置

任选其一：

1. **阶段 0 初始化邮件附件**（`.csv`）→ 归档到 `项目档案/00_进度计划/` 并自动导入  
2. **项目初始化 CLI**：`init_project.py --schedule-csv /path/to/file.csv`  
3. **手动导入**：
   ```bash
   python3 scripts/import_schedule_csv.py \
     --project-root "/path/to/project" \
     --source "项目档案/00_进度计划/your_schedule.csv"
   ```
4. **自动发现**：若 `project.json` 未指定路径，且 `00_进度计划/` 下**只有一个** `.csv`，则自动使用

`project.json` 会记录 `schedule_csv` 字段（相对项目根路径）。

## 表头（不区分大小写，支持中英文别名）

| 语义 | 必填 | 可识别表头示例 |
|------|------|----------------|
| 里程碑名称 | ✅ | `里程碑` `节点` `任务名称` `Task Name` `Activity` `Milestone` |
| 开始日期 | ✅* | `开始日期` `Start` `Start Date` `日期` `Date` |
| 结束日期 | 推荐 | `结束日期` `Finish` `Finish Date` `End` |
| 采购包 | 可选 | `采购包` `Package` `专业` `Discipline` |

\* 若只有结束日期列，也会当作单日里程碑处理。

## 日期格式

支持：

- `2026-05-01`
- `2026/5/1`
- `2026.05.01`
- `20260501`

## 示例

```csv
里程碑,开始日期,结束日期,采购包
开工,2026-05-01,2026-05-01,
竣工,2026-12-01,2026-12-31,
移交 Handover,2027-03-27,2027-03-27,
到货,2026-09-01,2026-09-30,BMS
IT-cabling 安装完成,2026-09-15,2026-10-15,IT-cabling
```

有「采购包」列时，节点名会自动组合为 `{采购包} {里程碑}`（如 `BMS 到货`），便于与付款节点语义匹配。

## 与付款节点的关系

导入后的里程碑供 `enrich_payment_nodes()` 使用，卡片付款表会显示 **计划时间区间** 列：

| 付款节点语义 | 对齐规则 |
|-------------|----------|
| 预付款 | ≤ 开工 |
| 到货 | 匹配包名 + 到货类里程碑，或卡片交期 |
| 安装/调试 | 匹配包名 + 安装类里程碑 |
| 验收/尾款 | ≤ 移交/竣工 |

## 后续格式扩展

你提供的 CSV 若表头不同，把样例文件发来即可扩展别名映射；Excel (`.xlsx`) 可另存 CSV 后导入，或后续加直接读 xlsx。
