系列 Skill 自查表

给「多个 Skill 连成一套」用的。查的是结构：谁能写、状态清不清、会不会抢同一份内容。 不查某一份说明书写得漂不漂亮——那是 Skill Creator 的活。

怎么用

按 1→6 的顺序填。先列对象，再列 Skill，再对「谁能写」。一次只查结构，先别改功能。填空会自动存在这台电脑的浏览器里。

1. 对象：系统真正在管的东西

合同、变更、请款、图纸、进度……先写这些，不要先写 Skill 名字。一张卡片一个对象。

2. Skill 清单：谁上场

现在才写 Skill。重点是：它可以单独用吗？单独用时许不许改整套的正式记录。

3. 谁能写

每一行（一个对象）的「写」尽量只有一个。两个都能写，必须在备注里写清：凭什么状态、谁先谁后。

待填

格子含义：写 = 可以改正式记录；读 = 只能看、只能引用；不许 = 碰都不许。

4. 状态闸门

按对象填，不要按 Skill 填流程。状态是闸门，不是标签。回退必须写清：已经发出去的许可怎么收回。
