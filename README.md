# 采购包技能包

这是一套给工装内装项目经理用的技能。管的是采购包：从建项目、读合同和报价，到履约、请款、变更，再到进度节点和以后要花多少钱。

用 Cursor 打开这个仓库，对话里就能用。不用再单独安装。

## 怎么用

1. 用 Cursor 打开本仓库。
2. 直接说人话，比如「新建项目」「帮我看这份 PDF」「处理待处理邮件」「这包该请款了」。
3. 只办一件事时，它只做那一件。比如你只要把进度计划转成表，它不会顺手去建采购包或写请款。

给人看的介绍页：用浏览器打开 `docs/采购包技能介绍.html`。

要把这套技能拷到 WorkBuddy，在仓库根目录运行：

```bash
python3 scripts/sync_skills_to_workbuddy.py
```

## 每套技能是干什么的

技能正文都在 `skills/` 里，一个文件夹一套。

| 文件夹 | 你什么时候用 | 它做什么 |
| --- | --- | --- |
| `new-project` | 新开一个项目 | 先问齐必填信息（含币种、是否含税），再建立项目文件夹 |
| `read-pdf` | 手里有报价单、合同、扫描件 | 把 PDF 里的字读出来。只读，不记账 |
| `mpp-to-excel` | 进度计划是 Project 文件或粗表 | 转成能给后面步骤用的表，也可以出一张甘特样式的表 |
| `critical-nodes` | 要知道到货、安装、验收大概在什么时候 | 从进度计划里推出这些节点，给人看的是「某月上旬 / 中旬 / 下旬」 |
| `po-flow` | 采购包的履约邮件：RFP、技术确认、下单、付款条件、合同 | 归档，更新采购包状态表，整理出卡片用的数据 |
| `vendor-card` | 要看某个采购包现在什么样 | 画出履约卡片。通常由履约那套技能来调用 |
| `payment-sheet` | 要按业主的请款单格式出表 | 生成请款申请页，并能下载一版式样对齐的 Excel。不算这笔该请多少，也不入账 |
| `payment-flow` | 该提醒请款，或供应商已经来请了 | 只盯每个包下一笔待请，记下请款走到哪一步。客户批复之后才算进已请金额 |
| `change-flow` | 来了变更：COD、PMI、技术确认、商务确认、变更单 | 记变更台账，把状态往下推，归档邮件。不定价，不改采购包状态表 |
| `mail-inbox` | 你把整封邮件放进项目的「待处理邮件」 | 认这封信该交给履约、请款还是变更。看不准的留在原地问你 |
| `cashflow` | 想知道以后每个月大概要付供应商多少 | 按月推算出账。只读现有台账，不改请款、履约、变更 |

## 旁边这几个文件夹

- `lib`：几套技能共用的底子。建项目文件夹、读写采购包状态表的规矩在 `lib/project-foundation`。谁先谁后的规矩在 `lib/skill-orchestration`。这不是你在对话里点名使用的技能。
- `docs`：给人看的介绍页，以及几张示例。
- `scripts`：把技能拷到 WorkBuddy 的工具。
- `.cursor`：Cursor 这个软件只从这里认技能和规矩。里面的 `skills`、`lib` 是指回仓库门口那两处的入口，正文不在这里。规矩文件也在这里，打开仓库就生效。

钥匙不会进仓库。读 PDF 的密钥、邮箱授权码只留在你这台电脑上。
